# GA4導入 作業報告

記録日時: 2026年11月27日 12時34分00秒 (JST)

## 目的・設計
公式サイトの測定ID G-QH59YMTGL8 を使用。トップ(日英)、ポートフォリオ、ブログ、製品・プライバシーページの異なる生成経路を、既存のprerender後のHTML処理に統一する。404・XMLは除外。本番ホストのみ、明示同意まではGA4を読み込まない。既存Vercel Analyticsは変更しない。GA4の広告関連設定を拒否し、Cookieをホスト単位・専用prefixに分離する。撤回時は送信を無効化しCookieを削除して再読み込みする。ページURLのquery/hashを計測用page_locationから除外し、参照元はoriginのみ渡すためキャンペーン等の詳細分析には制約がある。

## 変更
- scripts/analytics.mjs: HTMLタグ挿入を一元化
- public/site/analytics.js / analytics.css: 同意・撤回UIと本番GA4ロード
- scripts/analytics.test.mjs: 挿入・再実行・対象外ファイル・同意・拒否・撤回・プレビューの回帰テスト
- package.json / .github/workflows/ci.yml: buildに後処理を追加、node:testをCIに追加
- public/privacy.html: GA4のデータ・Cookie・撤回を告知

## 検証
既存CIはnpm install、npm run lint、npm run build (tsc -b含む)。npm testを追加。現時点では接続ツールからコミット作成済み、ローカル実行は未実施。PRのCIで結果を確認する。既存の独立したformatterは未整備のため今回の機能変更には含めない。実ブラウザでのGoogleタグ通信、Cookie削除、画面表示、実際の計測はデプロイ後に要確認。GA4管理画面で拡張計測、広告関連設定、データ保持・データ編集（個人情報の除外）、連携先を確認する。

## 引き継ぎ
最初に本報告、scripts/analytics.mjs、public/site/analytics.js、scripts/analytics.test.mjs、CIを読む。npm test / npm run lint / npm run build。公開環境で未同意・拒否時はGA4リクエストなし、同意時に一度ロード、撤回後停止、日英・主要ページを確認。リアルタイム/DebugViewを確認後Search Consoleと連携。問題時は本PRをrevertし、タグ・設定UI・ポリシーを一緒に戻す。
