01 / Web / コードから音楽へ

コードと音楽をつなげる

ソースコードは文字の連なりですが、ファイルの構造や使われている言語に特徴があります。Logiscoreはその構造を音楽として捉え直す実験的なアプリです。

JavaScript・TypeScriptはバイオリン、Pythonはフルート、Rustはチェロ、Goはフレンチホルンといった楽器へ割り当て、複数の言語を重ねた音楽を作ります。

02 / Web / コードから音楽へ

使い方

ブラウザでソースコードのフォルダを選択します。ツールは対象ファイルを読み込み、言語に応じた音のパターンを組み立てます。

生成したMIDIをブラウザで再生したり、ファイルとして利用したりできます。機密性の高いコードを扱う場合は、利用環境やブラウザ拡張機能なども確認してください。

03 / Web / コードから音楽へ

端末内で処理する理由

コードを音に変える処理は、RustをWebAssemblyへコンパイルしたエンジンで実行します。ソースコードをEnludusのサーバーへアップロードしない構成です。

ファイルをサーバーへ送らずに処理することは、個人の制作物から社内のコードまで扱いやすくするための設計上の判断です。

04 / Web / コードから音楽へ

技術実験としての発展

現在のMIDI生成機能に加え、音楽にデータを符号化して復元する音声伝送の実験も進めています。チェックサムや誤り訂正を組み合わせ、音として扱ったデータをどの程度復元できるかを検証しています。

ここで紹介している音声伝送の高度な機能は開発中のものを含みます。一般向けのWebデモで利用できる範囲は、実際の画面をご確認ください。
