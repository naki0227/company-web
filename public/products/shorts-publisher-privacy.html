Enludus Shorts Publisher Privacy Policy

Last updated: November 10, 2026

Enludus Shorts Publisher (the "Tool") is an internal command-line tool operated by Enludus, the trade name of Ibuki Nagase, a sole proprietor in Japan ("we"). The Tool uploads short videos that Enludus makes about its own apps to Enludus's own YouTube channel. It is not offered to the public, and only Enludus signs in to it.

YouTube API Services

The Tool uses YouTube API Services. By using the Tool, you agree to be bound by the YouTube Terms of Service. Information handled through YouTube API Services is also subject to the Google Privacy Policy.

What the Tool accesses

  • Google account authorization. When the channel owner signs in, Google issues OAuth tokens that allow the Tool to upload videos to that channel (scope https://www.googleapis.com/auth/youtube.upload). The Tool does not request access to watch history, subscriptions, comments, or any other channel data.
  • Videos and their details. The Tool sends the video file, title, description, tags, category, privacy setting, and related settings that we prepared ourselves.
  • Upload results. The Tool receives the ID and status of each uploaded video so we can confirm the upload worked.

The Tool does not collect any information about YouTube viewers or other users.

How information is stored and shared

  • OAuth tokens are stored only on the computer where the Tool runs, in a local file that is excluded from source control. They are not sent to any server operated by Enludus.
  • Upload results (video IDs and status) are kept in local logs on the same computer.
  • We do not sell, share, or transfer this information to third parties, and we do not use it for advertising.
  • The Tool does not use cookies and does not store information on any user's device other than the computer it runs on.

Revoking access and deleting data

The channel owner can revoke the Tool's access at any time from the Google Account security settings: https://myaccount.google.com/permissions. Revoking access makes the stored tokens unusable. We delete the local token file when access is revoked, and stored information obtained through YouTube API Services is deleted or refreshed within 30 days, as required by the YouTube API Services Developer Policies.

To ask for deletion or for any question about this policy, contact contact@enludus.com.

Changes

We may update this policy. The latest version is always on this page, with the date it was last updated.
