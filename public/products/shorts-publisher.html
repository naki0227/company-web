Enludus Shorts Publisher

An internal tool that uploads short videos about Enludus's own apps to Enludus's own YouTube channel.

Uses YouTube API Services

The tool uses the YouTube Data API v3 (YouTube API Services) to upload videos. It requests one permission only, https://www.googleapis.com/auth/youtube.upload, and calls one endpoint, videos.insert. It does not read data about other channels, viewers, comments, or analytics.

What it does

  1. We record real gameplay of our own apps (for example, Gojuon Minesweeper) and add narration from scripts we write and music we made ourselves.
  2. We write the title, description, and tags for each video.
  3. The channel owner signs in with Google once. The tool then uploads each video to our channel, and we check it in YouTube Studio.

Who can use it

Only Enludus. The tool is not offered, sold, or distributed to anyone else. The source code is public for transparency: github.com/enludus-daily/yt-pipeline.

Revoking access

The channel owner can revoke the tool's access at any time at myaccount.google.com/permissions. See the Privacy Policy for what is stored and how it is deleted.
